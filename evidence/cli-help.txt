$ cambc --help
Usage: cambc <COMMAND>

Commands:
  run-batch    Run independent matches from a four-column text manifest
  init         Create or refresh a cambc project: the SDK sources, maps and a bots/ directory under DIR (default: the current directory)
  shell-init   Print shell integration that enters the workspace after init
  add-to-path  Add cambc to PATH for this terminal session (prints setup instructions without shell integration)
  maps         Download the current published competition map pool
  login        Sign in with your platform account (session lasts seven days)
  submit       Upload a bot's source to your team's submissions
  bundle       Package a bot's source as a ZIP for uploading on the platform
  new          Create a bot, prompting for any missing details
  build        
  run          
  view         Open a replay in the visualiser: a .repl26a file, a match directory, or (by default) the most recent bundle under replays/
  mapeditor    Open the map editor, optionally loading a map path or a name from maps/ [alias: map-editor]
  help         Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

$ cambc run --help
Usage: cambc run [OPTIONS] <BOT_A> <BOT_B>

Arguments:
  <BOT_A>  
  <BOT_B>  

Options:
      --map <MAP>                Map file (.map26a): a path, or a bare name resolved under maps/ (default: the first .map26a file in maps/, alphabetically)
  -o, --out-dir <OUTDIR>         Directory for the replay bundle (default: replays/ in the project)
      --rounds <ROUNDS>          Rounds to play (default: play to the end)
      --fuel <FUEL_QUANTUM>      fuel per turn
      --view                     Open the replay in the visualiser after the match
      --statistics <STATISTICS>  Export final game statistics as JSON (requires a completed game)
  -h, --help                     Print help

Run independent matches from a four-column text manifest

Usage: cambc run-batch [OPTIONS] [MANIFEST]

Arguments:
  [MANIFEST]  Text file: bot-a-project bot-b-project map replay.repl26a (paths relative to this file)

Options:
      --jsonl <JSONL>                API v1 compiled-input JSONL manifest; stdout contains only machine events
      --jobs <JOBS>                  Maximum independent runner processes [default: 1]
      --rounds <ROUNDS>              Stop after this many game rounds; otherwise play until the game finishes
      --fuel-quantum <FUEL_QUANTUM>  
      --timeout <TIMEOUT>            Wall-clock seconds per match, including runner startup
      --color <COLOR>                [default: auto] [possible values: auto, always, never]
